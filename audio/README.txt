HOW TO ADD AUDIO FILES
========================

Place these two files in this folder:

  chime.mp3
  — A gentle chime/bell sound (0.5–2 seconds).
  — Plays when the envelope opens.
  — Free sources: freesound.org, mixkit.co (search "chime" or "bell")

  eid.mp3
  — Your personal voice message (any length).
  — Record yourself saying Eid greetings on your phone,
    then rename the file to eid.mp3.
  — This plays for ALL recipients (shared audio).
  — If this file is missing, the voice player is silently hidden.

Both files are OPTIONAL — the site works perfectly without them.
